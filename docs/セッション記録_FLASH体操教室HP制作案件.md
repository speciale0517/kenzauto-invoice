## 1. 経緯サマリ

福田氏の実家が営む体操教室からホームページ制作の依頼があり、受注に向けた壁打ちを行ったセッション。
最終的に「実績確保」を目的とした低予算・買い切り案件として、調査・企画・見積・資料作成までを一貫して進めた。

### 進行の流れ

1. **調査フェーズ** — FLASH体操教室の事業内容、現行ホームページの課題、費用相場を調査
2. **予算調整フェーズ** — 「実績づくりが目的、予算20万円以内」という制約を受け、相場調査とコストカット案を再検討
3. **資料化フェーズ** — 社内共有用PDF（グラフ付き）を作成
4. **先方提示資料フェーズ** — クライアント向けの提案書・見積書・ヒアリングシート・同意書ひな形を作成
5. **技術構成の見直し** — 「Studio」と「Claude Code（3rdStage作成）」の比較検討。買い切り前提でA/B 2プラン化
6. **資料の再設計** — 社内向けノイズ（実績づくり目的、保守オプション等）を排除し、先方が直接見るための視覚的スライド資料へ作り直しを開始
7. **外部ツール移行** — スライド作成をChatGPTに依頼するため、自己完結型プロンプトを作成

### 自社にとっての最低ライン

- 人日単価3〜5万円で逆算し、**20万円＝実働5〜6人日が上限**
- 15万円を下回ると実績目的でも赤字ラインと判断

### コストカット施策

- 削ってよい：ノーコード採用、ページ数を6枚に限定、原稿はクライアント記入、デザイン工程の簡略化、予約システム省略、ロゴ流用、修正回数の上限設定
- 削ってはいけない：独自ドメイン＋SSL、アクセス解析・計測、スマホ実機確認

## 4. 技術構成の検討（Studio vs Claude Code自社製作）

ユーザーからの質問「Studioとは何か。Claude Codeで作れば安くならないか」を受けて検証。

### 判明した事実

- **Studio**：日本製ノーコードツール。サーバー・SSL・CMS・フォームが一式含まれる月額課金サービス（Business プラン年47,760円）
- **実装費はほぼ変わらない**：デザイン・要件定義は技術選定と無関係。実装工数も自動化されている部分が多く、大差なし
- **差が出るのは「先方の年間ランニング費用」**：
  - Vercelの無料プランは商用利用禁止（規約上の制約。要有料化＝年約36,000円）
  - **Cloudflare Pages**（無料・商用利用可）＋**microCMS**（無料Hobbyプラン）の組み合わせが有力
- この構成により、年間維持費を **約50,000円 → 約5,000円** まで下げられる

### 2プラン化の決定

| | プランA：Studio版 | プランB：3rdStage作成版 |
|---|---|---|
| 制作費（税込） | 187,000円 | 198,000円 |
| 納期 | 約6週間 | 約8週間 |
| 年間維持費 | 約50,000円 | 約5,000円 |
| 現状（年11,000円）比 | 約39,000円増 | 約6,000円減 |
| 3年累計 | 337,000円 | 213,000円（約3ヶ月で逆転） |

## 6. 提案書の作り直しに至った経緯（重要な軌道修正）

初版の「ご提案書・御見積書」に、以下のような**社内向けの内容が混入**していることをユーザーが指摘：

- 「初回制作事例協力割引」の詳細な条件列挙（実績づくりが目的である旨が透けて見える）
- 保守オプションなど、買い切り契約と矛盾する記載
- 「含まれないもの」を延々と並べた自衛的な表
- テキスト量が多く、ITに詳しくない先方には理解しづらい構成

### ユーザーからの要望（作り直しの指示）

1. 先方が直接見る資料として、社内向けノイズを排除
2. A/Bプラン比較は**対比構造**にする（左右並べ、上下や別ページに分けない）
3. 営業トークをしながら両者で見る前提の資料
4. 「この金額でこのレベルが作れる」というお得感を演出
5. イラストなど視覚的要素を増やし、テキスト依存を減らす

### 確認した4つの方針（AskUserQuestionで確定）

| 質問 | 回答 |
|---|---|
| 資料形式 | **A4横・スライド形式**（営業トークで一緒に見る前提） |
| 見積金額の見せ方 | **資料内に含める** |
| 「初回制作事例協力割引」の表記 | **残す**（ただし簡潔に） |
| 記載する会社情報 | **社名と担当者名のみ**（3rdStage／福田） |

## 8. ChatGPT移行の判断

スライド制作の続きを、ユーザーの判断で**ChatGPTに作業させる**方針に変更。
Claude Codeでの作業は一時中断し、ChatGPT向けの自己完結型プロンプトを作成した。

### プロンプトの設計思想

ChatGPTには会話の文脈が引き継がれないため、以下をすべて自己完結させた：

- **資料の使われ方**の明確化（読ませる資料ではなく指差しながら説明する資料）
- **出力形式**の指定（A4横HTML、インラインSVG、印刷→PDF対応）
- **禁止事項**（社内事情・保守オプション・自衛的な表・脅し文句）
- **全事実データ**（教室情報、強み、課題、競合、2プランの数値、更新手順、相場データ、契約条件、スケジュール）
- **16枚のスライド構成**（1枚ごとに図解方法まで指定）
- **デザイン指定**（配色：プランA=緑／プランB=青で統一、文字サイズ、イラストスタイル）

作成したプロンプトは `docs/ChatGPT用プロンプト_提案資料作成.md` として保存・送付済み。
