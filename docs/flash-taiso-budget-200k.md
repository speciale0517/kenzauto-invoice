# FLASH体操教室 HP制作 — 20万円以内で収めるための相場調査とコスト設計

作成日: 2026-09-16
前提: **営業担当・福田氏の実家の体操教室／自社の制作実績づくりが主目的／予算20万円以内**

---

## 0. 結論（先に）

1. **20万円は「安売り」ではなく、フリーランス相場のど真ん中**。
   個人・フリーランスへの依頼相場は **10〜30万円**（複数ソースで一致）。
   20万円はその上位側なので、値付けとして卑屈になる必要はまったくない。
2. **20万円に収める鍵は「値引き」ではなく「工程を削る設計」**。
   Web制作の人日単価は概ね3〜5万円/人日。20万円＝**実働5〜6人日が上限**。
   この枠に入る仕様を最初から切ることが唯一の正解で、
   値引きで無理やり入れると赤字＋無限修正コースになる。
3. **削っていい7項目と、削ってはいけない3項目がある**（後述）。
   特に **GA4/Search Consoleの計測は絶対に削らない**。
   実績づくりが目的なら、成果物より「**体験申込が月◯件増えた**」という数字が最大の資産になるため。
4. 提案の形は「**定価328,000円 → 初回制作事例協力割引 → 税込198,000円**」。
   最初から20万が定価だと、2件目以降の価格が上げられなくなる。

## 1. ホームページ制作の世間相場（2026年・ソース付き）

### 1-1. 依頼先別の相場 ← これが今回いちばん効く軸

| 依頼先 | 相場 | ソース |
|---|---|---|
| 大手制作会社 | 300万円〜 | お名前.com WEB学園 |
| 中小の制作会社 | 80〜150万円 | お名前.com WEB学園 |
| 一般的な制作会社 | 30〜100万円 | 格安ホームページ.jp |
| **フリーランス（個人）** | **10〜50万円**／別ソース **10〜40万円**／別ソース **10〜30万円** | お名前.com／格安ホームページ.jp／Xserver・シーズプランニング |
| テンプレート型の格安業者 | 0〜15万円 | 格安ホームページ.jp |
| 月額制サブスク型 | 初期0円＋月5,000〜30,000円（月2,596円〜の例も） | 格安ホームページ.jp／お名前.com／シンク |
| 自作 | 0〜10万円（有料テーマ・素材・学習コスト込みなら10〜20万円） | お名前.com／StockSun |

**→ 20万円の立ち位置**
「フリーランス相場（10〜30万）の中〜上位」かつ「制作会社の最低ライン（30万）の下」。
つまり **“個人・小規模事業者として妥当に取れる金額の上限付近”**。
クライアントから見れば「制作会社に頼むより10〜80万円安い」という説明が成立する。

### 1-2. 同業比較：STUDIO（ノーコード）制作代行の相場

- **小規模サイト（1〜3ページ）で30〜80万円、中央値45万円**（Studio制作代行の相場解説記事）

**→ ここが提案の最大の武器。**
同じSTUDIOを使った制作代行の中央値が45万円。
今回の198,000円は **中央値の約44%、下限30万円と比べても3割強安い**。
「相場の半額以下」と根拠を持って言える。

### 1-3. 地域相場（宮崎県）

- 宮崎県内の制作会社の制作費用は **30万円〜300万円** と幅広い（StockSun／humhum）
- 宮崎県内にも「格安対応」を掲げる制作会社カテゴリが存在する（Web幹事の分類）
- 月額22,000円〜のサブスクプラン（制作＋運用＋保守込み）を出す地場業者もある

**→ 地方だから極端に安いということはない。** 宮崎でも下限は30万円。
20万円は**県内の制作会社の下限を下回る**価格帯。

### 1-4. ページ単価の相場（これが「削る」設計の根拠になる）

| 項目 | 相場 | ソース |
|---|---|---|
| トップページ | **5〜20万円/ページ** | Web幹事 |
| 下層ページ | **5,000〜5万円/ページ**（別ソース：2〜7万円/ページ） | Web幹事／Bties |
| ライティング（原稿制作） | 1ページあたり数万円 | Web幹事 |
| ディレクション費 | **制作費総額の10〜30%** | GIG／LIG／Web幹事 |

**→ ページ数を3枚減らせば、相場ベースで 1.5〜15万円分の工数が消える。**
これが20万円に収める最大のレバー。

### 1-5. 撮影費の相場

| 撮影形態 | 相場 | ソース |
|---|---|---|
| 時間制 | 1時間 2万円前後 | Lancers |
| 商品・物撮り（商用） | **半日3〜4万円／1日7〜8万円** | OrderPhotoStudio |
| 出張撮影（高単価帯） | 半日10万円／全日20万円 | 出張撮影ナビ |
| 別途かかるもの | 出張費・交通費・スタジオ代・アシスタント人件費 | 各社共通 |

**→ 撮影を外注に入れた瞬間、20万円の枠の15〜20%が飛ぶ。** ここは要判断（後述）。

### 1-6. 保守・運用費の相場

- 継続的な管理費は **月5,000円〜2万円が約6割、平均4.1万円**（お名前.com）

**→ 保守は制作費に含めず、月額別契約にするのが相場的にも正しい。**

## 2. 「最低金額」はいくらか — 3つの下限と、その理由

### 下限① 市場としての最低金額：実質 0〜5万円

- クラウドソーシングでは **簡単なホームページ制作が1〜5万円で募集**されている（Lancers系の発注ノウハウ記事）
- **LP（1ページ）の相場は5万円ほど**（StockSun）
- **月額制サブスクは初期費用0円**（複数社）
- 自作なら 0円

**ただしこの価格帯には構造的な理由がある：**

| 価格 | 実態 | 何が起きるか |
|---|---|---|
| 0〜3万円 | テンプレに文字を流すだけ。1〜3ページ | 差別化ゼロ。競合と並べた瞬間に負ける |
| 初期0円のサブスク | **「所有」ではなく「利用」** | **解約するとサイトが消える**。所有権は制作会社側、データもドメインも手元に残らない（シンク／jarea／ファンフェアファンファーレ） |
| 5万円前後 | 1ページLP | 今のkitenn.jpと同じ轍 |

> ⚠️ **サブスク型は今回は絶対に選んではいけない。**
> FLASH体操教室が現在まさに「他社のドメイン配下で、解約＝サイト消滅」という
> 状態で困っているのに、同じ構造の契約に移すのは提案として筋が通らない。

### 下限② 原価としての最低金額：約5万円

| 実費 | 金額 |
|---|---|
| 独自ドメイン | 1,500〜4,500円/年 |
| STUDIO Business（年払い） | 約47,760円/年 |
| 撮影（内製なら0円） | 0円 |
| **実費合計** | **約5万円/年** |

※ただし**この実費はクライアント名義で直接契約させる**ので、制作費には乗せない（後述・削減策⑫）。

### 下限③ 自社にとっての最低金額：**15万円**

Web制作の人日単価は概ね3〜5万円/人日。今回の想定実働を積むと：

| 工程 | 想定工数 |
|---|---|
| ヒアリング・要件定義・サイト設計 | 0.5〜1人日 |
| デザイン（トップ＋下層テンプレ） | 1.5〜2人日 |
| STUDIO実装（6ページ） | 1.5〜2人日 |
| 原稿整理・流し込み・スマホ調整 | 0.5〜1人日 |
| 公開設定（ドメイン/SSL/GA4/SC/OGP） | 0.5人日 |
| **合計** | **4.5〜6.5人日（実働36〜52時間）** |

- **20万円 ÷ 50時間 ＝ 時給4,000円** → 妥当
- **15万円 ÷ 50時間 ＝ 時給3,000円** → ぎりぎり許容（実績づくりの対価と割り切る範囲）
- **10万円 ÷ 50時間 ＝ 時給2,000円** → **実績目的でも赤字。受けるべきでない**

**→ 結論：15万円が自社としての下限。20万円が適正。**
15万を切る提案は、値引きではなく「仕様をさらに削る」ことでしか成立しない。

## 3. コストカットできる箇所 — 削減額と理由

### ✅ 削っていい（＝20万円に収める7つのレバー）

| # | 施策 | 削減額の目安 | 理由・根拠 |
|---|---|---|---|
| ① | **ノーコード（STUDIO）を採用し、コーディング工程を持たない** | 構造的に数十万円 | 外部コーダーへの外注費が不要になり、開発期間が短縮されるため（Studio制作代行の解説記事が明示している「ノーコードが安い理由」そのもの）。これが20万円を成立させる土台 |
| ② | **ページ数を12→6に絞る** | **1.5〜15万円** | 下層ページの相場が5,000〜5万円/ページ。6枚削れば相場ベースでこの額が消える。最初は「トップ／コース一覧＋料金／コーチ紹介／出張指導（B2B）／よくある質問／お問い合わせ」の6枚で必要十分 |
| ③ | **原稿はクライアント記入（ヒアリングシート方式）** | **3〜10万円** | ライティングは1ページ数万円が相場。前回作ったヒアリングシートに書いてもらい、こちらは**整形・推敲のみ**に留める |
| ④ | **デザインカンプ工程を省き、STUDIO上で直接デザイン** | 2〜5万円 | Figmaで精緻なカンプを作って承認→実装、の二度手間をなくす。ノーコードの最大の利点。**ただしトップページだけはラフ共有して合意を取る**（後戻りコストのほうが高いため） |
| ⑤ | **予約システム・会員管理を作らない** | **10万円以上** | LINE公式アカウント（無料枠）＋ Googleフォーム／STUDIO標準フォームで代替。体操教室の規模で予約SaaSは過剰。フェーズ2送り |
| ⑥ | **ロゴ・イラストを新規制作しない** | 3〜8万円 | 既存ロゴを使う。データがなければトレース程度に留める |
| ⑦ | **修正回数を「デザイン2回・原稿2回」に固定** | （青天井の防止） | 安く受けた案件が赤字化する最大の原因は修正の無限ループ。**身内案件ほど「もうちょっとだけ」が発生しやすい**ので、金額より先に回数を合意する |

### ⚖️ 条件付きで削る（判断が要る）

| # | 施策 | 削減額 | トレードオフ |
|---|---|---|---|
| ⑧ | **プロ撮影を外注しない** | **3〜10万円** | 相場は商用半日3〜4万円、出張だと半日10万円。**枠の15〜50%を占める**ので削減効果は最大。ただし**写真の質＝体操教室サイトの質**。<br>**折衷案を推奨**：低単価カメラマンに**2〜3時間だけ**依頼（1.5〜3万円）してレッスン風景と講師カットだけ押さえ、器具・外観・駐車場は自分でスマホ撮影 |
| ⑨ | **MEO（Googleビジネスプロフィール）を初期設定のみに限定** | 2〜5万円 | 初期設定（営業時間・コース・写真投稿）は**30分で終わるので含める**。月次の投稿運用は含めない＝保守オプション化 |
| ⑩ | **ディレクション費を圧縮** | 1〜3万円 | 相場は総額の10〜30%。身内案件なので打合せをLINE・オンライン中心にして回数を減らせる。**ただしゼロにはしない**（要件定義を飛ばすと作り直しになる） |

### 🚫 削ってはいけない3項目（これを削ると実績にならない）

| # | 項目 | なぜ削ってはいけないか |
|---|---|---|
| ❶ | **独自ドメイン＋HTTPS** | 今回の依頼の根本原因がこれ。現サイトは `http://` で他社ドメイン配下。ここを直さないなら作り直す意味がない。**費用は年1,500〜4,500円**。削る理由が存在しない |
| ❷ | **GA4 ＋ Search Console ＋ フォーム送信計測** | **実績づくりが目的なら、ここが最重要。**<br>綺麗なサイトは「見せられる」だけだが、「**公開3ヶ月で体験申込が月2件→7件**」は営業で刺さる**数字の実績**になる。作業は0.5人日以下。費用対効果が圧倒的 |
| ❸ | **スマホ実機での表示確認** | 保護者の閲覧はほぼスマホ。実機確認を飛ばすと公開後にクレームで工数が倍returnする |

## 4. 見積書の組み立て案（税込198,000円）

### 4-1. 提示の形

> **通常価格 328,000円（税別）**
> **初回制作事例協力割引 −148,000円**
> **──────────────**
> **今回制作費 180,000円（税別） / 198,000円（税込）**

**なぜ定価を見せるか：**
最初から20万円を定価にすると、**2件目以降に値上げできなくなる**。
「実績づくりのため特別に」という形にしておけば、次の案件は定価から交渉を始められる。
定価328,000円は、フリーランス相場10〜50万円の中に収まっており、
STUDIO制作代行の中央値45万円より安いので、定価としても無理がない。

### 4-2. 内訳

| 項目 | 通常 | 今回 | 内容 |
|---|---|---|---|
| ディレクション・要件定義・サイト設計 | 60,000 | **35,000** | ヒアリング、サイトマップ、構成案 |
| デザイン | 100,000 | **55,000** | トップ1枚＋下層共通テンプレ1枚 |
| STUDIO実装（全6ページ） | 110,000 | **60,000** | レスポンシブ対応込み |
| 原稿整理・流し込み | 30,000 | **15,000** | ※原稿はクライアント提供 |
| 公開設定 | 28,000 | **15,000** | 独自ドメイン接続／SSL／GA4／Search Console／OGP／MEO初期設定 |
| **合計（税別）** | **328,000** | **180,000** | |
| **合計（税込）** | 360,800 | **198,000** | ✅ 予算内 |

### 4-3. 別途（クライアント名義で直接契約・実費）

| 項目 | 金額 |
|---|---|
| 独自ドメイン | 年1,500〜4,500円 |
| STUDIO Business（年払い） | 約47,760円/年（月3,980円相当） |
| LINE公式アカウント | 0円〜 |
| 撮影（任意・後述） | 0円 or 15,000〜40,000円 |
| **年間ランニング合計** | **約5〜6万円/年** |

> 💡 **ランニングを制作費に含めず、クライアント名義の直接契約にする理由は3つ**
> 1. 見積総額が下がり、20万円枠に収まる
> 2. 立替え・請求漏れのリスクがなくなる
> 3. **ドメインとアカウントがクライアント名義になる**＝将来の移管トラブルを防ぐ
>    （現在まさに他社サービス依存で困っている教室なので、ここは説明しやすい）

### 4-4. オプション（別途見積・「やらないこと」の明示）

| オプション | 金額 |
|---|---|
| プロ撮影（2〜3時間・レッスン＋講師） | 15,000〜40,000円 |
| コース個別ページ追加 | 15,000円/ページ |
| ロゴ制作 | 30,000〜80,000円 |
| 保守・更新代行 | 月5,000円〜（相場は月5,000〜2万円が約6割） |
| 予約・月謝決済システム連携 | フェーズ2で別途 |

**「やらないこと」を見積書に書くのが、安く受ける案件で最も重要。**
ここを書かないと「当然入っていると思った」で無償対応が発生する。

## 5. 実績づくり案件だからこそ、金額以外で取るべきもの

値引き148,000円の**対価**として、以下を契約・合意事項に入れる。
これがないと「ただ安く作っただけ」で終わり、実績確保という本来の目的を達成できない。

- [ ] **制作実績としての公開許可**（自社サイト・提案資料・SNSへの掲載）
- [ ] **お客様の声（推薦コメント）の提供**（公開後1〜2ヶ月時点。顔写真付きなら価値が倍）
- [ ] **公開後3ヶ月の成果数値を共有してもらう許可**（体験申込件数・問い合わせ件数）
      → 「体験申込 月2件→7件」のような**数字の実績**は、デザインより営業で効く
- [ ] **紹介の依頼**（同業の体操教室、取引のある幼稚園・保育園）
      → 園への出張指導チャネルがあるので、**園の紹介はかなり現実的**
- [ ] 修正回数の上限（デザイン2回・原稿2回）と、超過時の追加料金
- [ ] 素材提出期限と、遅延時の納期スライド条項

## 6. 身内案件の落とし穴（先に潰しておく）

| リスク | 対策 |
|---|---|
| **伝言ゲーム**（福田氏を経由して実家とやり取り） | **意思決定者（教室の代表）と直接つながる**。福田氏は同席でOKだが、確認は本人に |
| **「ついでにこれも」が無限に増える** | 見積書に「やらないこと」を明記。追加は都度見積 |
| **請求しづらくなる／支払いが後回しになる** | 着手金50%・納品時50%を最初に取り決める。身内だからこそ書面で |
| **修正が口頭で飛んでくる** | 修正依頼はLINEでも良いので**必ずテキストで**。回数カウントの根拠になる |
| **素材（写真・原稿）が集まらず納期が延びる** | 期限を切る。延びた分は納期を後ろ倒し（自分の工数で吸収しない） |

## 7. 補助金について

小規模事業者持続化補助金などでウェブ関連費が対象になる場合がありますが、
**今回の規模（20万円）では申請工数に見合わない可能性が高い**です。
申請書類の作成・報告義務の手間を考えると、素直に自費で進めるほうが早く公開できます。
※制度内容・公募状況は時期によって変わるため、実際に検討する場合は
  申請時点の公募要領で必ず確認してください。
