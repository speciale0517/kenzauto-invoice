## 2. 現在のホームページ詳細

### 2-1. 事実確認

| 項目 | 内容 |
|---|---|
| URL | `http://kitenn.jp/flash/` |
| 利用サービス | **KITENN**（アイコムティ株式会社／宮崎市）「低コストで運営できる1ページのホームページサービス」 |
| 料金 | 年額 11,000円（税込） |
| 構成 | **1ページ**（サービス仕様上） |
| ドメイン | **独自ドメインなし。他社ドメインのサブディレクトリ** |
| 通信 | **`http://` = HTTPS非対応**（検索インデックス上のURLがhttp） |
| 問い合わせ | フォームに希望曜日・クラスを記入 → **後日折り返し連絡** |

### 2-2. 課題（優先度順）

**🔴 最優先**

1. **HTTPS非対応**
   Chrome等で「保護されていない通信」警告が出る。
   何より、**子どもの氏名・年齢・保護者の連絡先を平文フォームで送らせている**状態は、
   個人情報の取り扱いとして看過できない。ここだけでも即対応の理由になる。
2. **独自ドメインがない／サブディレクトリ運用**
   - 検索評価が自社に蓄積されない（資産にならない）
   - 名刺・チラシ・園への配布物に書けるURLとして弱い、覚えられない
   - **サービス解約＝サイト消滅**。11年分の露出が他社に握られている
3. **1ページ構成で情報が決定的に不足**
   6コースあるのに、コース別の「料金・曜日・時間・会場・定員・持ち物」が書けていない。
   保護者の意思決定に必要な情報が揃っていない。

**🟡 重要**

4. **予約導線が弱い**：フォーム→後日連絡。競合はLINEで即応。
   問い合わせの熱量は数時間で冷める。
5. **料金が検索で出てこない**：「料金非公開」は教室選びで最大級の離脱要因。
6. **SNS連携が確認できない**：Instagram公式アカウントが検索で見つからなかった【要確認】。
   体操は「動き」が商品なので、**動画SNSとの相性が極めて良いのに使えていない**可能性。
7. **OGP/構造化データ未設定と推測**：LINEやInstagramでURLを共有してもサムネが出ない。
   地域ビジネスの拡散は口コミ＝LINE共有が主なので、ここは効く。
8. **Googleビジネスプロフィール（MEO）の整備状況が不明**【要確認】
   「宮崎市 体操教室」の実際の主戦場は**Google マップ**。HPより先に効く場合すらある。

**🔵 移行時の技術的注意（重要）**

9. **301リダイレクトが張れない可能性が高い**
   `kitenn.jp` は他社ドメインのため、リダイレクト設定の可否は提供元の裁量。
   → **検索評価・被リンクを引き継げない前提**で計画すべき。対策：
   - 新旧を一定期間（3〜6ヶ月）並行運用し、旧ページに移転告知＋新URLリンクを掲載
   - Googleビジネスプロフィール、各種ポータル、SNSプロフィール、名刺、チラシのURLを一斉差し替え
   - 新ドメインで Search Console 登録・サイトマップ送信を初日に実施

## 4. どのサービスを使うか

### 4-1. 比較

| サービス | 初期難度 | 教室側の更新しやすさ | デザイン自由度 | 年額目安 | 評価 |
|---|---|---|---|---|---|
| **STUDIO** | 中 | ◎（CMS・日本語UI） | ◎ | 約4.8万円（Business年払い） | **◎ 本命** |
| Wix | 低 | ◎ | ○ | 2〜4万円 | ○ 対抗 |
| ペライチ | 低 | ○ | △ | 約1.8〜4.7万円 | △ 1ページ寄りで**今と同じ轍** |
| WordPress | 高 | △（要教育） | ◎ | 1.5〜3万円＋**保守必須** | △ 保守負担が教室に重い |
| Next.js + Vercel | 高 | ×（要制作者） | ◎ | ほぼ0円 | △ 属人化・更新が止まる |
| Jimdo / Ameba Ownd | 低 | ○ | △ | 0〜3万円 | △ 拡張性不足 |

### 4-2. 推奨：**STUDIO（Business プラン・年払い）**

理由：

1. **HTTPS自動・独自ドメイン対応**（現状の最大課題が即解決）
2. **CMS機能**で「お知らせ」「コース」「スケジュール」を**教室側が自分で更新できる**
   → 保守費を抑えられる＝クライアントのランニング負担に説明がつく
3. デザイン自由度が高く、テンプレ臭が出ない（競合と差がつく）
4. 国産・日本語サポート・管理画面が日本語 → **携帯電話1本で運営している教室でも触れる**
5. フォーム標準搭載、独自フォント、レスポンシブ自動

**プラン選定の注意**：Mini(590円/月)・Personal(1,190円/月)は個人向け区分です。
法人サイト・CMS・ページ数の要件を満たすか、**契約時点の公式規約で必ず確認**すること。
迷ったら Business（3,980円/月・年払い）で見積もるのが安全。

### 4-3. 周辺ツール構成（推奨セット）

```
[STUDIO]  ← 本体サイト（独自ドメイン + HTTPS）
   ├─ 体験予約フォーム（STUDIOフォーム or formrun）
   ├─ LINE公式アカウント  ← 体験予約・振替連絡・休講連絡（台風/警報時に必須）
   ├─ Googleビジネスプロフィール ← MEO。写真投稿＋クチコミ導線
   ├─ Instagram（縦型動画）← 体操は「動き」が商品。相性が最良
   └─ GA4 + Search Console ← 効果測定
```

**月謝決済・会員管理のオンライン化**（hacomono / Coubic / STORES予約 等）は、
初期費用と月額が跳ね上がるため**フェーズ2に回すのが妥当**。
まずは「LINE＋フォーム」で十分に成果が出ます。

## 6. その他の提案

### 6-1. 集客の主戦場は「Googleマップ」

「宮崎市 体操教室」で保護者が最初に見るのは地図です。
**Googleビジネスプロフィールの整備はHP制作と同等以上に効きます**。

- 営業時間・コース・写真20枚以上・投稿の定期更新
- **クチコミ依頼の仕組み化**（体験後にLINEでレビューリンクを送る）
- 提案に「MEO初期設定」を含め、月次運用は保守契約のオプションにする

### 6-2. SEOキーワード設計

- 地域系：`宮崎市 体操教室` `佐土原 体操教室` `宮崎 幼児 体操`
- **悩み系（狙い目）**：`逆上がり できない 宮崎` `跳び箱 跳べない 教室`
  `宮崎 バク転 教室` `宮崎 マット運動 苦手`
  → 悩み系は競合が手薄で、かつ**入会意欲が最も高い層**。
    コース紹介とは別に「お悩み別ページ」を作る価値があります。
- B2B：`宮崎 幼稚園 体操 外部指導` `保育園 体操教室 出張`

### 6-3. コンバージョン設計

- スマホ画面下部に**「無料体験を予約」固定ボタン**（常時表示）
- ファーストビューで「0歳から全国大会まで。宮崎・佐土原の体操教室」と一発で伝える
- **料金は必ず公開**（非公開＝離脱）
- 問い合わせ後の返信SLAを決める（例：24時間以内）。LINEなら即応可能

### 6-4. 保護者向け限定エリア（フェーズ2）

パスワード保護ページに、時間割PDF／年間予定／大会日程／振替申請フォーム／
休講のお知らせを集約。**問い合わせ電話が減り、指導時間が守れる**＝教室側の直接的メリット。

### 6-5. 契約・権利まわり（受注側として必ず握ること）

- **ドメイン・各種アカウントは必ずクライアント名義で取得する**
  （制作者名義にすると、後の移管でトラブルになります）
- 著作権の扱い（譲渡 or 利用許諾）を明記
- 写真の肖像権責任はクライアント負担であることを明記
- 修正回数の上限（例：デザイン2回・原稿2回）と、超過時の追加料金
- 素材提出期限と、遅延時の納期スライド条項
- 公開後の保守範囲（何をどこまで、月何回まで）

### 6-6. 補助金の可能性【要確認】

小規模事業者持続化補助金など、ウェブ関連費が対象になる制度がある場合があります
（ウェブ関連費は補助対象経費の一定割合までという上限が設けられることが一般的）。
宮崎県・宮崎市の独自のデジタル化支援も含め、**申請時点の最新公募要領で必ず確認**が必要です。
使えれば、クライアントの予算判断が一気に前進します。

### 6-7. 運用が止まらない仕組み

サイトは公開後1年で腐ります。原因は「誰も更新しないから」。

- **更新担当者を1人決める**（コーチの誰か）
- 保守契約に「月1回の更新枠」を含める
- 更新項目をルーチン化：月初にお知らせ1本／大会結果／体験会告知
